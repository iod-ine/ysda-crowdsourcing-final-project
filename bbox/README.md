# Первичная разметка бабочек

В [проекте bbox №11824](https://tasks.yandex.ru/requester/project/11824) семь исполнителей разметили 400 фотографий. На каждую взрослую бабочку приходилась отдельная рамка. Исполнитель мог также отметить отсутствие бабочек, сомнение или ошибку загрузки. Интерфейс и иллюстрированные правила сохранены в [шаблоне](bbox-template.json) и [инструкции](bbox-instruction.html).

| Этап | Состав и правило |
|---|---|
| [Обучение](https://tasks.yandex.ru/requester/project/11824/pool/6870102) | Бесплатно, 15 фото на одной странице. Для допуска к экзамену требовались F1 ≥ 0,80 при IoU ≥ 0,75 и отсутствие ложных рамок на пустых фото. Навык 21767 получал значение 100. |
| [Экзамен](https://tasks.yandex.ru/requester/project/11824/pool/6870155) | Пять фото на одной странице. На трёх по одной бабочке, на одном две, на одном взрослых бабочек нет. Для допуска требовалось сопоставить все рамки при IoU ≥ 0,75 без пропусков и лишних рамок. Навык 21764 получал значение 100. За 17 подтверждённых сдач по 2,50 ₽ выплачено 42,50 ₽ плюс 17 ₽ комиссии. |
| [Основной пул](https://tasks.yandex.ru/requester/project/11824/pool/6870160) | Перекрытие 1. Всего 44 страницы по 10 фото, включая 40 контрольных показов. Приняты все 44 страницы по 6 ₽. Расход с комиссией составил 369,60 ₽. |

## Контроль и приёмка

Десять контрольных фото показывались по четыре раза. Для оценки одного фото требовалось совпадение числа объектов. Для нескольких рамок порог должен был пройти каждый объект при взаимно однозначном сопоставлении. Правильный пустой ответ получал 1. После первого успешного контроля (≥ 0,60) к автоприёмке допускались все ожидающие страницы исполнителя, в том числе страницы без контрольного фото. Два результата ниже 0,60 подряд блокировали дальнейшую работу и автоприёмку.

При повторной проверке на фото 761346880 нашли вторую, тёмную бабочку. В исправленном эталоне две рамки. С ним порог прошли 37 из 40 контрольных ответов. У всех семи исполнителей сохранилось право на оплату.

## Файлы и связь с ревью

- [Исходные ответы](../data/bbox_answers.jsonl) содержат 440 строк. Поле `kind` разделяет 400 рабочих ответов (`work`) и 40 показов контроля (`control`). `status`, `boxes` и `comment` передают ответ разметчика. Координаты нормализованы. `page_status` относится к оплате всей страницы, `control_score` и `control_verdict` — к проверке контрольного фото. Исполнители обозначены B01–B07, страницы — P01–P44.
- По `photo_id` рабочий ответ связывается с [вердиктами ревьюеров](../data/review_answers.json), а затем с [финальным эталоном](../data/golden_set.json). При сравнении исходных рамок с полем `labeler_boxes` в выгрузке ревью следует учитывать округление до шести знаков.
- [inputs/](inputs/) содержит файлы загрузки обучения, экзамена и основного пула. В [private/](private/) сохранены эталоны этапов и состав страниц, которые читают скрипты. `gold5.json` относится к итоговому экзамену, `gold.json` — к архивной версии на 10 фото. [Локальный редактор](control-annotator.html) использовался для подготовки контрольных рамок.
- [score.py](score.py) проверяет выгрузки обучения и экзамена локально. [sync_exam.py](sync_exam.py) реализует выдачу навыков и приёмку экзамена через API. [main_qc.py](main_qc.py) проверяет контрольные рамки основного пула. Команды справки из папки `bbox/`: `python3 score.py --help`, `python3 main_qc.py check --help`. Скрипты используют стандартную библиотеку Python 3. Для работы с API требуется собственный токен в `YANDEX_TASKS_TOKEN`.
