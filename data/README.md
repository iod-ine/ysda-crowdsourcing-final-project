# Данные и результаты

В проекте два набора по 400 фотографий. Первый собрала и разметила команда: по нему выбирали модель. Второй выдан для Контеста: для него в репозитории есть входные фото по ссылкам и предсказания моделей. Наборы не пересекаются по `photo_id`.

## От первичной разметки до эталона

| Файл | Содержимое |
|---|---|
| [bbox_answers.jsonl](bbox_answers.jsonl) | 440 ответов. Фильтр `kind == "work"` оставляет 400 рабочих фото, `kind == "control"` даёт 40 контрольных показов. |
| [review_answers.json](review_answers.json) | В массиве `photos` для каждого кадра сохранены предложенные рамки, ответы проверяющих и решение. |
| [golden_stats.json](golden_stats.json) | Статистика объектов и голосов. В `manual_review.log` зафиксированы решения по 19 спорным фотографиям. |
| [golden_set.json](golden_set.json) | Эталон для оценки. В массиве `items` каждой фотографии соответствует один `photo_id` и список рамок `result`. У 128 фото список пуст. |
| [evaluations/](evaluations/) | Построчные отчёты GroundingDINO, OWLv2 и Qwen на командном эталоне. CSV для DINO и OWLv2 относятся к базовым прогонам; для Qwen опубликован прогон с промптом v1.0 после восстановления JSON. |

Чтобы проследить решение по одному кадру, возьмите рабочую строку в `bbox_answers.jsonl`, найдите тот же `photo_id` в `review_answers.json`, затем сравните рамки с `result` в эталоне. Источник и лицензия находятся по этому же ключу в [таблице iNaturalist](../samples/main_candidates.tsv).

## Контест

[dataset.jsonl](dataset.jsonl) содержит идентификаторы и ссылки на 400 экзаменационных фото. Каждая строка предсказаний содержит `photo_id`, массив `boxes` и поле `error`. Координаты `left`, `top`, `width`, `height` нормализованы к размеру кадра. Пустой массив при `error: null` означает, что модель обработала фото и не нашла бабочек.

Для отправки команда выбрала [предсказания Qwen](qwen_prediction.jsonl). Здесь также сохранены [предсказания OWLv2](owl_prediction.jsonl), [предсказания GroundingDINO](dino_prediction.jsonl) и [примеры с рамками](images/examples/).
