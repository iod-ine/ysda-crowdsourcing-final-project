# Выборка iNaturalist

Мы включили в выборку дневных и ночных бабочек, кадры с несколькими объектами, внешне похожих насекомых, гусениц и растения. Такие примеры позволяют проверить, пропускает ли детектор мелкую вторую бабочку и принимает ли за бабочку цветок или другое насекомое. Категория наблюдения описывает источник фото. Окончательное число объектов устанавливали по изображению во время [разметки](../bbox/README.md) и [ревью](../review/README.md).

| Файл | Назначение |
|---|---|
| [collect_inaturalist_groups.py](collect_inaturalist_groups.py) | Собирает ссылки через API iNaturalist, проверяет лицензию фотографии `cc0`, устраняет повторы по ID фотографии и наблюдения. |
| [inat_links/](inat_links/) | Исходные таблицы по группам и таксонам. |
| [main_candidates.tsv](main_candidates.tsv) | 450 кандидатов с `photo_id`, URL изображения и наблюдения, сведениями об авторстве, лицензии и группе источника. |
| [shuffled_for_pools/](shuffled_for_pools/) | Распределение фотографий резерва по этапам и HTML-превью. Фактический состав страниц bbox сохранён в [файлах загрузки пула](../bbox/inputs/). |

Точные 400 фото командного набора задаёт [golden_set.json](../data/golden_set.json). Для каждого из них в таблице кандидатов есть запись с лицензией CC0. Чтобы скачать именно эти изображения, выполните из корня репозитория:

```sh
uv run materialize -i data/golden_set.json -o data/images/evaluation
```
